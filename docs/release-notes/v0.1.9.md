## 新增

- 实现 Mihon/Komga Tracker 的标准卷级阅读进度同步。
- 服务端会严格以 Mihon 发来的 `lastBookNumberSortRead` 更新当前 Series 的已读 Book 状态，支持进度前进和回退。
- 页面图片成功返回后，会记录推断页码进度：最近加载页、该 Book 最大加载页、总页数和更新时间。
- Series / Book 信息页新增阅读进度展示：Mihon 同步状态和推断页码进度。

## 调整

- 推断页码只用于信息页展示，不影响 Mihon Tracker 的已读状态，也不会自动把 Book 标记为已读。
- Release 工作流改为读取 `docs/release-notes/{tag}.md` 作为 GitHub Release 正文；文件缺失时发布失败，避免发布页只有过短的自动说明。

## 部署

- GitHub Release 继续自动编译 Windows、Linux、macOS 二进制文件并上传 SHA256 校验和。
- Docker Hub 镜像继续在 tag 发布时自动构建 `linux/amd64` 和 `linux/arm64` 多架构版本。
