# v1.3.0

## 纯前端 Web 阅读器支持

- 新增 `GET /api/v1/server/capabilities`，方便独立网页客户端探测后端版本和能力。
- 新增 `GET /api/v1/books/{bookId}/next` 与
  `GET /api/v1/books/{bookId}/previous`，用于阅读器在同一 Series 内跳转上一卷/下一卷。
- 新增 `DELETE /api/v1/books/{bookId}/read-progress`，支持单本漫画清除真实页级进度、
  标记为未读。
- 新增 `docs/WEB_CLIENT_API.md`，给纯前端网页阅读器和 AI Agent 说明 Base URL、
  CORS、分页、Series/Book、页面图片、进度同步和懒加载约束。

## CORS 与 Local Network Access

- 管理页新增“允许的 Web 前端 Origin（CORS）”多行输入框，默认关闭，每行一个精确
  Origin，不支持 `*` 或 `localhost:*` 通配。
- CORS 只对 `/api/v1/*` 和 `/api/v2/*` 生效，管理 API 不暴露跨域访问。
- 支持 `OPTIONS` 预检；当浏览器发送
  `Access-Control-Request-Private-Network: true` 时，后端返回
  `Access-Control-Allow-Private-Network: true`，方便 Cloudflare Pages / GitHub Pages
  等 HTTPS 前端由用户浏览器访问局域网 HTTP 后端。

## 文档与安全说明

- README 增加独立网页阅读器接入说明。
- 架构文档补充 CORS 中间件、capabilities、Book sibling 和进度删除接口。
- SECURITY 明确：一旦配置外部网页 Origin，该网页可以跨域读取 `/api/v1` / `/api/v2`
  的书库、漫画图片和阅读进度接口，只应填写可信前端。
