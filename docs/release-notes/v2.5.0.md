# MangaAlpha v2.5.0

本次版本聚焦**中文简介增强源切换**、**网络串流加载进度可视化**与**跨平台更新检测（含 Android 应用内校验安装）**三大体验升级。

## 主要变更

### 1. Bangumi 离线索引库多源切换（默认中文简介增强镜像）
- 新增 Bangumi 离线索引库数据源切换能力，在「管理后台 → Bangumi 刮削中心」及 `/api/agent/v1/bangumi/archive/source` 可自由选择：
  - **中文简介增强镜像（默认，`zh_cn`）**：指向 [`xJogger/bangumi-archive-zh`](https://github.com/xJogger/bangumi-archive-zh)，与官方 `bangumi/Archive` 100% 同构，仅将全站非 NSFW 外文简介翻译为自然流畅的简体中文；原本已是中文的简介及其他字段（标题、别名、评分、排名、作者、标签等）均保持原样。
  - **官方原版（`official`）**：直接拉取上游 `bangumi/Archive` 原始快照。
  - **自定义兼容源（`custom`）**：支持填入任意兼容 `aux/latest.json` 格式的镜像元数据 URL。
- 切换数据源后点击「检查并更新离线索引库」，会因快照 SHA256 摘要变化自动重新导入，并通过既有的增量同步引擎把已匹配作品的未锁定简介平滑刷新。

### 2. 网络串流漫画实时加载进度显示
- 后端 `internal/archive` 新增轻量无锁实时加载状态追踪器（`LoadTracker`），并开放标准兼容扩展接口 `GET /api/v1/books/{bookID}/load-status`（支持可选 `?page=N` 参数），**完全不改动既有 Komga `/api/v1/books/{id}/pages` 响应契约**，后续 v2.6.0 Android 原生阅读器可直接复用。
- 内置网页阅读器（`/reader/*`）全面接入加载进度反馈：
  - **首次打开远程压缩包构建索引阶段**：显示当前串流来源（`115 网盘串流` / `WebDAV 串流` / `本地归档`）、阶段提示、已读取字节/进度条、已识别页数与耗时；
  - **单页网络串流读取阶段**：快速本地/缓存页面（`< 240ms`）零干扰零额外请求；慢速网络串流页实时显示页码、来源、下载分块/解压阶段、字节进度与等待耗时。

### 3. 全平台版本更新检测 + Android 应用内校验安装
- 新增跨平台 `internal/updater` 更新检测引擎：
  - 默认每 24 小时后台静默检查一次 GitHub Releases 最新稳定版，**自动复用「Bangumi 刮削中心」配置的网络代理**（未配置则直连）。
  - 管理后台新增顶部轻量可忽略版本提醒横幅，并在「缓存与设置 → 软件版本与更新检测」卡片展示当前/最新版本、更新日志、24 小时自动检查开关、立即检查按钮、对应平台安装包下载链接，以及 Docker 环境下的 `docker pull` 更新命令一键复制（桌面端与 Docker 端仅提示与指引，不强行原地自替换程序）。
  - 同步开放 Agent 接口：`GET /api/agent/v1/update`、`POST /api/agent/v1/update/check`、`PUT /api/agent/v1/update/config`。
- **Android 独立版应用内更新**：
  - 原生「手机端设置」页新增「应用版本与更新」卡片，支持手动检查更新、查看更新日志、实时下载进度条以及一键下载安装；
  - 下载复用 Go 端代理设置，并强制核对 Release 中的 `SHA256SUMS` 校验和，通过纯 AOSP `PackageInstaller` 拉起系统更新确认（首次安装引导授权「允许安装未知应用」）。

## 升级说明

- 服务端、Docker 与 Android 正式包均可直接覆盖升级，数据与设置向后兼容；已有 Bangumi 离线索引库在下次检查更新或切换数据源时自动平滑切换。
- 若在 Android 端使用应用内覆盖安装，请确保当前已安装的 APK 为官方正式签名版本。
