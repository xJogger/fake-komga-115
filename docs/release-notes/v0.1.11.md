# v0.1.11

## 新增

- Series 详情页新增手动生成系列封面、强制重建封面、生成全部 Book 归档索引、强制重建全部索引。
- Book 详情页新增当前 Book 归档索引生成和强制重建。
- 详情页维护任务后台串行执行，支持查看进度、错误摘要和取消。
- 新增索引耗时、系列封面生成耗时、真实 Range 下载平均速度统计。
- 管理页服务状态区域汇总全局平均索引耗时、平均封面耗时和真实下载平均速度。

## 修复

- 维护任务为空时 API 明确返回空数组，避免详情页任务面板在没有历史任务时显示脚本错误。

## 说明

- 默认维护操作会跳过已存在且仍匹配当前文件版本的封面或索引。
- 强制重建按钮带警示样式和二次确认，可能产生额外 115 Range 流量。
- 下载速度只统计真正从 115 downurl 成功读取的 HTTP Range 字节；缓存命中和失败请求不计入。
