# v2.0.0

`fake-komga-115` 从 115 漫画串流扩展为支持多存储源的自托管漫画书库，内置书架、简体中文阅读器和 Bangumi 元数据刮削，同时保留 Komga 兼容接口。

## 从 v1 升级前请先看

- **请先停掉旧服务，备份整个数据目录。** Docker 用户请备份挂载到 `/data` 的原有数据卷或目录，再使用相同的挂载启动新版本。备份可能含有令牌等凭据，请妥善保存。
- **首次启动 v2 后，先打开网页设置管理员账号密码。** 此前 API 和客户端不会放行。初始化后，在 Mihon 的 Komga 扩展或 Koharia 的 Komga 服务器设置中填入管理员账号密码；支持自定义请求头的客户端或工具也可用后台生成的 API Key。
- **原有外部 CORS 白名单已移除。** 独立托管的网页阅读器不能再按 v1.3.0 的跨域配置直接连接服务。可以改用同源托管的内置书架和阅读器；本次不改动独立前端项目。
- 继续使用原数据目录即可迁移旧书库、115 文件标识、阅读进度、索引和封面。升级不需要重新扫描或刮削。已标为 NSFW 的系列默认在前台隐藏，可在后台切换显示。若需要回退到 v1，请用升级前的备份恢复，不要直接用旧版打开已迁移的数据库。

## 功能更新

- **多存储源**：115 网盘、本地目录、Windows 映射盘或 Linux SMB/CIFS 挂载、WebDAV 可同时使用。目录扫描不读压缩包内容；远程漫画按需分块，本地漫画随机读文件。SMB 挂载异常导致根目录为空时，拒绝覆盖已有扫描结果。
- **网页书架与阅读器**：内置筛选、继续阅读、简体中文双页阅读器、页级进度同步和自动深浅色。手机版顶部导航不再吸顶；长卷名不会撑开继续阅读按钮，页码仍完整显示；优化了 Mihon WebView 的输入和 Bangumi 搜索弹窗。
- **Bangumi**：支持本地离线索引、实时查询、自定义代理、增量与批量刮削、封面缓存和手动绑定。改进繁简异体字、短标题、卷数尾缀和轻小说识别；真正的合集不会把其中一部作为默认候选或自动绑定。
- **管理与兼容**：增加单管理员鉴权、隐藏书库、NSFW 开关和 AI Agent 管理 API。保留 Mihon/Koharia 接入；后台和 README 补充了 115 授权流程。
