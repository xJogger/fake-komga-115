## MangaAlpha 2.3.0

本次版本合并交付原 2.2 与 2.3 路线图的全部能力，涵盖**分层叠加联合库**、**库级定时自动化流水线**、**来源标注与 Bangumi 油猴脚本联动**、**大书库数据库与检索性能优化**、**Koharia 深度兼容（含收藏夹 / 阅读列表）**、**日夜双套统一小鱼图标**，以及**发布包与构建产物命名统一为 `mangaalpha`**。

### 分层叠加联合库（OverlayFS 风格）
- **多物理库按优先级合并**：支持将多个物理书库（如本地/SMB → WebDAV → 115）合为一个逻辑「联合库」（`provider_type='union'`）。跨层自动剥离各库根目录首段、按归一化相对路径对齐，并按自然文件名重排卷序。
- **卷级互补与透明容灾**：不同层卷数不一致时自动做卷级叠加（上层缺卷透出下层）；上下层存在同名文件但文件大小不同时由上层覆盖；读取任意页面失败（断连/报错/缺文件）时按层优先级自动回退到下层副本，各层物理单册保持独立 `zip_indexes` 与缓存键互不污染。
- **无痛迁移与双向进度保障**：物理库纳入联合库后自动成为子库（对前台书架与 Komga 客户端隐藏，管理后台保留独立扫描能力且扫完自动静默刷新所属联合库）；支持 1 对 1 归属约束、One-Shot 模式一致校验与删除保护；首次纳入自动继承 Bangumi 元数据、只读复用已有封面文件、继承阅读进度并迁移收藏夹 / 阅读列表引用；后续在联合库产生的阅读进度双向同步回写底层物理副本，解散联合库后进度无损保留。
- **大库增量物化优化**：联合库刷新采用内存 Diff 增量物化（无变化行零写入、零触发器、不误触 `updated_at` 与书架缓存版本）、`WITHOUT ROWID` 源映射表、多行批写与 `bulk_mode` 批量触发器守卫，十万册级联合库增量刷新仅需数秒。

### 库级定时自动化流水线（移除旧全局自动扫库）
- **移除旧全局设置**：彻底删除全局设置中不再使用的 `auto_scan_enabled`、`auto_scan_interval_minutes` 与 `scan_on_startup`。
- **单库 / 联合库定时流水线**：按**服务器本机时区**配置每日固定时间或每周固定星期+时间触发，后台持久化运行记录并支持实时进度查看与随时取消；串行执行 **扫库（联合库支持多选本次仅扫哪些子库，如只扫顶层本地库）→ 联合库合并刷新 → Bangumi 增量刮削 → 缺封面未匹配作品自动补首卷封面**。
- **安全护栏**：本地 Bangumi 离线库未就绪时自动跳过刮削与补封面；自动补封面上限默认均为 `0`（不自动补封面）且支持每库独立配置；本地/SMB 与 WebDAV 均启用根目录 0 条目防误清空保护；任一扫库失败或取消均立即中止后续步骤。

### 漫画来源标注与 Bangumi 油猴脚本联动
- **书库与文件来源标注**：首页、全局搜索/筛选、收藏夹与阅读列表等跨库视图卡片新增「书库名 · 来源」简洁标识（单书库内部视图不重复显示）；作品详情页（含联合库层组成、每卷生效来源与备用副本）与单册详情页始终展示完整书库与来源信息（绝不暴露凭据或敏感 URL）；内置阅读器（`/reader/*`）保持不变。
- **Bangumi 一键跳转与油猴脚本**：新增 `GET /bgm/{subjectID}` 直达跳转入口（未登录自动登录后回跳，单版本直达详情、多版本直达 `?versions=1`、未命中提供按标题检索入口）与 `GET /api/v1/bangumi/lookup?subject_id=...` 探测接口；管理后台 Bangumi 页提供一键生成专用 API Key 并本地注入下载的 `.user.js` 油猴脚本（密钥仅在浏览器本地拼接，绝不经由 URL 或服务端日志暴露）。

### 数据库与大书库查询性能优化
- **SQLite 存储、索引与检索优化**：启用 `synchronous=NORMAL`、16 MiB 页缓存与内存临时表；为 `series` 表新增由触发器增量维护的 `books_count`、`sort_modified_at`、`sort_created_at` 聚合列，补齐排序、分类、`series_metadata` 覆盖检索与外键级联索引（含 `series_thumbnails(source_book_id)` 与 `maintenance_runs`）。
- **大库检索与请求取消保护**：重写搜索与列表查询（物化候选集 + 系列优先 `OR` 合并 + `EXCEPT` NSFW 隔离），消除大库全表扫描与 SQLite 变量上限错误；区分客户端主动取消（`499`）、超时（`504`）与真实服务异常（`500`）；`Counts()`、`ScrapeSummary()`、`Authors()` 纳入版本化书架缓存与异步预热；HTTP API 默认开启 `gzip` 压缩。
- **升级提示**：首次从 `v2.1.x` 升级启动时会自动建表建索引并一次性回填系列汇总列（数十万册书库通常耗时十余秒，后续重启恢复毫秒级）；升级前建议先停止服务并备份数据目录。

### Koharia 深度兼容 + 内置书架「收藏夹 / 阅读列表」
- **搜索兼容**：新增 Komga / Koharia 检索语法解析器，完整支持 Koharia 的 `(<q>) OR tag:(<q>)` 联合搜索、字段前缀（`title:`、`tag:`、`author:`、`publisher:`、`genre:`、`status:` 等）、`AND` / `OR` / `NOT` / 引号与 `sort=relevance` 相关性排序，并扩展 `POST /api/v1/{series|books}/list` 条件处理。
- **阅读历史与进度同步**：补全 `readProgress` 的非空整数 `page`、`created`、`lastModified` 与 `readDate` 字段；新增轻量级 Komga SSE 事件流（`GET /api/v1/sse/v1/events`）实时广播进度与收藏变更；新增 90 天进度重置墓碑表，在大书库下优化 Koharia 全局无过滤 `GET /api/v1/books?unpaged=true&deleted=false`，仅返回存在活跃阅读进度或 90 天内被重置进度系列的全部可见单册。
- **收藏夹与阅读列表（API + 网页书架）**：完整实现 Komga v1 Collections / ReadLists 全套读写接口与 `GET /api/v2/authors` 分页作者接口；内置网页书架新增「收藏夹」（`/collections`）与「阅读列表」（`/readlists`）页面及作品/单册页快捷加入入口，严格遵守隐藏书库与 NSFW 隔离。

### 统一日夜双套小鱼图标
- 网页书架导航、登录/初始化页与浏览器标签页图标按**书架有效日夜模式**统一切换：**日间模式**使用黑底白鱼，**夜间模式**使用白底黑圈线稿鱼。
- 内置阅读器（`/reader/*`）标签页图标同样跟随书架日夜模式切换，不改变阅读器画布与自身主题；同时补充 `GET /favicon.ico` 路由避免 404 日志。

### 命名与兼容说明
- 自 `v2.3.0` 起，GitHub Release 服务端归档与可执行文件统一命名为 `mangaalpha_vX.Y.Z_<os>_<arch>` / `mangaalpha`（`mangaalpha.exe`），Capabilities / Agent Manifest 服务名更新为 `MangaAlpha` / `MangaAlpha Agent API`（如使用自动化更新脚本，请注意适配新压缩包与二进制名称）。
- **兼容不变项**：Docker 镜像名 `blacktal/fake-komga-115`、容器内入口命令、`FK115_*` 环境变量、默认数据目录与数据库文件名、认证 Cookie / API Key / 浏览器本地存储键、Android 包名以及所有既有书库/系列/单册 ID 均保持完全不变。
