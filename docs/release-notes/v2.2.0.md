## MangaAlpha 2.2.0

本次更新聚焦**大书库数据库查询性能优化**、**Koharia 全功能兼容（含内置书架收藏夹 / 阅读列表）**、**日夜双套统一小鱼图标**，以及**发布包与构建产物命名统一为 `mangaalpha`**。

### 数据库与大书库查询性能优化
- **SQLite 存储与索引优化**：启用 `synchronous=NORMAL`、16 MiB 页缓存与内存临时表；为 `series` 表新增 `books_count`、`sort_modified_at`、`sort_created_at` 聚合列（由 SQLite 触发器增量维护，首次升级时事务内一次性回填），并补充排序、分类筛选与 `series_metadata` 覆盖索引。
- **消除高开销全表扫描与变量上限错误**：修复大批量 `IN (...)` 查询超过 SQLite 变量上限的问题（统一分块批查）；重写「已读 / 阅读中」查询路径直接由 `book_read_progress` 驱动；`Counts()`、`ScrapeSummary()`、`Authors()` 纳入版本化书架缓存与异步预热；HTTP 接口默认支持 `gzip` 响应压缩。
- **升级提示**：首次从 `v2.1.x` 升级启动时会自动新增表、索引并一次性回填系列汇总列（数十万册书库通常耗时十余秒，后续重启恢复毫秒级）；升级前建议先停止服务并备份数据目录。

### Koharia 深度兼容 + 内置书架「收藏夹 / 阅读列表」
- **搜索兼容**：新增 Komga / Koharia 检索语法解析器，完整支持 Koharia 的 `(<q>) OR tag:(<q>)` 联合搜索、字段前缀（`title:`、`tag:`、`author:`、`publisher:`、`genre:`、`status:` 等）、`AND` / `OR` / `NOT` / 引号与 `sort=relevance` 相关性排序，并扩展 `POST /api/v1/{series|books}/list` 条件处理。
- **阅读历史与进度同步**：补全 `readProgress` 的非空整数 `page`、`created`、`lastModified` 与 `readDate` 字段；新增轻量级 Komga SSE 事件流（`GET /api/v1/sse/v1/events`）实时广播进度与收藏变更；新增 90 天进度重置墓碑表，在大书库下优化 Koharia 全局无过滤 `GET /api/v1/books?unpaged=true&deleted=false`，仅返回存在活跃阅读进度或 90 天内被重置进度系列的全部可见单册，大幅减小响应体积并准确同步已读/重置未读状态。
- **收藏夹与阅读列表（API + 网页书架）**：
  - 完整持久化与实现 Komga v1 Collections / ReadLists 全套读写接口（含 `collection_id` / `readlist_id` 筛选、列表上下卷导航、封面回退及隐藏书库/NSFW `filtered` 隔离），并新增 `GET /api/v2/authors` 分页作者接口。
  - 内置网页书架顶部新增「收藏夹」（`/collections`）与「阅读列表」（`/readlists`）页面，支持新建、编辑、删除、手动排序、移除，以及在系列详情页和单册详情页一键加入或新建。

### 统一日夜双套小鱼图标
- 网页书架导航、登录/初始化页与浏览器标签页图标按**书架有效日夜模式**统一切换：**日间模式**使用黑底白鱼，**夜间模式**使用白底黑圈线稿鱼。
- 内置阅读器（`/reader/*`）标签页图标同样跟随书架日夜模式切换，不改变阅读器画布与自身主题；同时补充 `GET /favicon.ico` 路由避免 404 日志。

### 命名与兼容说明
- 自 `v2.2.0` 起，GitHub Release 服务端归档与可执行文件统一命名为 `mangaalpha_vX.Y.Z_<os>_<arch>` / `mangaalpha`（`mangaalpha.exe`），Capabilities / Agent Manifest 服务名更新为 `MangaAlpha` / `MangaAlpha Agent API`。
- **兼容不变项**：Docker 镜像名 `blacktal/fake-komga-115`、容器内入口命令、`FK115_*` 环境变量、默认数据目录与数据库文件名、认证 Cookie / API Key / 浏览器本地存储键、Android 包名以及所有既有书库/系列/单册 ID 均保持完全不变。
