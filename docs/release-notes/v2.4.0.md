## MangaAlpha 2.4.0

本次版本同时推进 **全平台脱敏诊断与排障基础**、**Android 独立版体验与局域网模式**、**WebDAV / 本地与 SAF 归档读取加固**，以及 **Bangumi 离线数据库定时更新与元数据自动增量同步** 和 **系列页多版本折叠交互优化**。

### 全平台脱敏诊断日志与排障导出
- **共用白名单脱敏引擎（`internal/diagnostics`）**：按白名单字段记录启动、扫描、目录列出、归档索引、单页读取、WebDAV/SAF 失败与耗时等关键事件，自动过滤并脱敏密码、Token、Cookie、API Key、完整 URL、非回环 IP 与私人路径；本地限量轮转保存至 `<DataDir>/diagnostics/`（总上限约 2 MiB，不自动上传），进程启动失败时也会直接落盘便于定位。
- **管理后台与 Agent API**：管理后台「缓存与设置」页新增脱敏诊断日志卡片，支持精简/详细排障模式切换、实时预览、导出 `.txt` 报告与清空；同步开放 `/api/agent/v1/diagnostics*` 接口。

### Android 独立版体验升级与局域网服务
- **原生「手机端设置」页**：新增零外部依赖的轻量原生 `SettingsActivity`，可从常驻通知的「手机端设置」动作（小米 MIUI / HyperOS 等系统默认单行折叠静音通知，下拉或长按常驻通知即可展开「手机端设置 / 停止」快捷按钮）、管理后台顶栏或启动页进入；即使 WebView 白屏或内嵌服务启动失败，也能查看状态、启停服务、切换详细诊断并保存/分享脱敏日志。
- **手机充当局域网服务器（双监听隔离）**：默认关闭；在原生设置页开启（强制要求已完成管理员密码初始化）后，在保持应用内 WebView 独立走 `127.0.0.1` + Cookie 守卫不变的前提下，额外开启 `0.0.0.0:<端口>`（默认 `25600` 可改）局域网监听器，走标准账号密码 / Basic Auth / `X-API-Key` 鉴权并展示可一键复制的本机局域网地址；重启应用记住开关与端口（端口冲突时仅局域网监听提示错误，不影响本机阅读）。
- **状态栏与安全区适配**：跟随书架浅色/深色模式及进入 `/reader/*` 阅读器自动切换系统状态栏/导航栏底色与图标明暗，兼容 Android 8–15 Edge-to-Edge 与异形屏安全区。
- **同机 CloudDrive2 使用建议**：在手机上连接同机 **CloudDrive2** 扫描大型书库或长时间阅读时，建议在系统省电 / 应用管理中将 **CloudDrive2** 与 **MangaAlpha** 两者的后台权限均设为「无限制」，防止系统冻结后台进程导致中断。
- **签名预览流水线**：通用化 Android CI，推送 `feat/v*` 分支自动产出带正确预览版本号（低于正式版）的签名 APK，正式发布由 `v*` 标签直接签发。

### WebDAV（含 CloudDrive2）与本地 / SAF 归档读取加固
- **WebDAV 稳定性提升**：保留真实底层错误分类到诊断日志；为 `PROPFIND` 与 `FetchRange` 增加针对瞬断与 HTTP `408`/`429`/`502`/`503`/`504` 的有限退避重试；重定向时保留 `Range` 并在跨主机跳转时剥离 `Authorization`；当入库 `Size=0` 时自动通过 `HEAD`/`PROPFIND` 校准真实文件大小；容忍 `Content-Range` 尾段短读。
- **本地与 Android SAF 兼容加固**：打开本地/SAF 文件句柄时通过 `Stat`/`Seek` 自动校准缺失或滞后的文件大小；当 `.zip/.cbz` 与 `.rar/.cbr` 实际文件头与扩展名不符时自动按魔数回退解析；Android SAF 增加有界 LRU 文档 ID 缓存与 `EXTRA_LOADING` 短暂重试，减少翻页重复遍历目录树导致的失败。

### Bangumi 离线库定时更新与元数据自动增量同步
- **定时检查与跳过重复下载**：在管理后台「Bangumi 刮削中心」与 Agent API 新增离线库定时更新（支持按服务器本机时区每周固定星期+时间或每月固定日期+时间，默认推荐周三 `06:00` 衔接上游周更）；检查 `aux/latest.json` 时优先比对快照名称与 SHA256 摘要，未更新则直接跳过 ~430 MB 下载。
- **新快照自动增量同步元数据**：每当导入新版离线索引库后（重启通过已同步版本指纹跳过重复刷库），自动按 `bgm_subject_id` 在纯本地对全库已匹配作品做字段级 diff，仅更新发生变更且未锁定（`*_lock = 0`）的元数据字段（评分、排名、标题/排序名、别名、简介、连载状态、总卷数、出版日期、出版社、作者、分类、标签与 NSFW 标记）；文本与数组字段采用「新值非空才覆盖」保护，不重下封面、未变更作品零写入。

### 系列页面多版本切换与同 Bangumi ID 默认选中优化
- **默认折叠的移动端友好多版本面板**：系列详情页的多版本切换从原生下拉弹出菜单改为页面内**默认折叠**的展开面板，清晰展示各版本的书库、来源、目录名（最多 2 行防溢出）、册数与最近阅读状态，版本较多时内部滚动不顶飞卷列表；只要作品已绑定 Bangumi 且存在 ≥2 个可见版本即自动展示，不再受限于「合并同名作品」开关。
- **统一按卷数最多优先**：同 Bangumi ID 存在多个版本时，书架「合并相同 Bangumi ID」的默认代表版本、详情页多版本切换列表排序，以及 `/bgm/{subjectID}` 与油猴脚本默认跳转目标统一按 `卷数最多 (books_count DESC)` → `联合库优先` → `书库名 / 目录名 / ID` 排序，同时保留顶部「继续最近阅读」快捷入口。
