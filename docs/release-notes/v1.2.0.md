# v1.2.0

## 体验提升

- 新增 Koharia 兼容支持：补齐 `client-settings`、`users/me`、结构化 Series/Book 搜索
  和 Library 筛选所需接口。
- README 和管理页推荐客户端新增 Koharia；Mihon + Komga 扩展仍继续支持。
- `POST /api/v1/series/list` 与 `POST /api/v1/books/list` 支持 Library、One-Shot、
  read status、全文搜索和排序。缺少真实元数据的 genre/tag/author/publisher 等筛选
  返回空结果，避免误以为条件已被忽略。

## 阅读进度

- 新增 `PATCH /api/v1/books/{bookId}/read-progress`，支持 Koharia 按 Book 同步页码。
- Book DTO 返回 `readProgress.completed`、`readProgress.page` 和
  `readProgress.readDate`。
- `read_status` 筛选严格使用客户端真实同步进度：无记录为 `UNREAD`，有页码未完成为
  `IN_PROGRESS`，完成为 `READ`。
- 图片加载推断页码继续只用于信息页展示，不会污染真实阅读状态。

## 兼容与安全

- 新增本地 `client_settings` 表，仅允许保存 `koharia.*` 与 `webui.*` 前缀的非敏感
  客户端设置，并限制 key/value 长度。
- 数据库迁移会自动补齐页级进度字段和客户端设置表。
