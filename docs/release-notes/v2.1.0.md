## MangaAlpha 2.1.0

原 fake-komga-115 更名为 **MangaAlpha**。现有服务端二进制名、Docker 镜像 `blacktal/fake-komga-115`、端口、配置与数据目录不变；Mihon / Koharia 不必重配。

Android 图标、网页导航、浏览器标签页和项目 Banner 统一换为黑底白鱼；README 保留另一款线稿鱼印章。

- **Android 独立预览版**：ARM64，支持手机目录（系统只读授权）、115 和 WebDAV，内置书架与阅读器，可通过前台服务在后台运行，并可从通知停止。不依赖家中服务端或同步其书库。签名安装包为 `mangaalpha-arm64.apk`；可覆盖使用同一证书和包名的签名预览，但与旧调试版是两个独立应用。Android 扫库使用应用私有 SQLite 临时目录，修复找不到临时路径（6410）时报错的问题。
- **书架体验**：首页区块独立加载，书库列表不再等待分类选项；常用查询有缓存和异步预热，「继续阅读」改为从进度表查询。
- **Bangumi**：按排名排序，未收录排名靠后；网页可选合并同一 Subject ID 的作品，再进入详情切换版本。原始系列、卷及进度保持独立，Komga 客户端列表不合并。
- **封面**：作品页可生成首卷第一页封面；书库可批量仅补缺封面且未绑定 Bangumi 的系列，本地 / SMB 默认全库，115 / WebDAV 默认最近更新 5 部。
- **WebDAV 修复**：测试连接、创建及编辑账号时各发送正确的字段，支持完整邮箱用户名；新增书库时能进入和选用任意层级的 WebDAV 子目录；设置页补充同手机 CloudDrive2 的地址示例。

**Android 预览已知问题**：接入手机同机 CloudDrive2 时，扫库可能中途停止，已入库的漫画也可能加载不出页面；通过 SAF 添加手机本地目录时，有个别漫画已扫库并刮削但无法阅读。这两种情况仍待排查。
